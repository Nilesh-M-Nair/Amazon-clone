# new-repo

This is a starter repository scaffold created from the Amazon-clone workspace.

## Getting started

1. Initialize git (if needed):
   ```bash
   git init
   ```
2. Add files and make your first commit:
   ```bash
   git add .
   git commit -m "Initial commit"
   ```

## Structure

- `.gitignore` — common ignores for Node/JavaScript projects.
- `LICENSE` — MIT license template.
